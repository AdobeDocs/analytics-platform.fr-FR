# Informations sur la conversation

Les informations sur les conversations vous permettent d’analyser les conversations (à partir de LLM ou d’êtres humains) à grande échelle et en fonction du contexte de ces conversations dans le parcours client complet. Grâce aux informations de conversation, vous pouvez comprendre l’impact des agents sur les résultats réels des utilisateurs et utilisatrices.

Les informations de conversation abordent les problèmes que vous pouvez rencontrer. Par exemple :

* Vous ne disposez pas d’insight pour savoir ce qui se passe lorsque les clients interagissent avec des agents (LLM ou humains) dans le cadre du parcours.
* Vous ne pouvez pas comprendre :
  * ce que les agents disent aux clients à grande échelle.
  * comment le client interagit avec les agents à grande échelle.
  * quel est l’impact global de ces interactions sur les indicateurs de performance clés ?
* Vous créez des expériences agentiques sous pression pour s’adapter aux préférences changeantes des utilisateurs et utilisatrices.

## Fonctionnement

Les informations de conversation reposent sur trois fonctionnalités principales :

* Collecte de données : collecte tous les points de données nécessaires pour que les utilisateurs puissent comprendre comment LLM et les agents effectuent leurs tâches.
* Extraction du signal : transforme les invites et les réponses non structurées (également appelées conversions) en points de données à signaler, comme l’intention et le sentiment. Pour que les utilisateurs puissent créer des rapports sur ces points de données à grande échelle.
* Reporting : analysez les conversations à grande échelle dans le cadre du parcours client pour déterminer l’efficacité et le retour sur investissement d’un agent.
