# Report Builder

Cet article décrit comment [!DNL Report Builder] peut être utilisé pour implémenter le cas d’utilisation d’exportation de données [ suivant ](overview.md) :

* Rapports ad hoc et récurrents

## Introduction

[!DNL Report Builder] [!DNL Report Builder] est un complément Microsoft Excel qui extrait les données Customer Journey Analytics dans des blocs de données d’un classeur. Les utilisateurs professionnels qui connaissent déjà Excel peuvent créer des rapports récurrents sans apprendre à utiliser Analysis Workspace ou SQL.

## Informations supplémentaires

Chaque bloc de données dans [!DNL Report Builder] renvoie jusqu’à 50 000 lignes. Pour récupérer davantage de lignes, utilisez les options **[!UICONTROL Page]** et **[!UICONTROL Lignes]** pour extraire des données dans des pages séquentielles au-delà de la limite de 50 000 lignes. Voir [Filtrer les dimensions](/help/report-builder/filter-dimensions.md) pour plus d’informations.

Vous pouvez planifier la diffusion d’un classeur par e-mail ou l’exporter vers une destination cloud, telle qu’Amazon S3, Google Cloud Platform ou Azure. Pour plus d’informations](/help/report-builder/schedule-reportbuilder.md) consultez les sections [Planifier des classeurs en les partageant par e-mail et [Planifier des classeurs en les exportant vers des destinations cloud](/help/report-builder/report-builder-export.md).

Pour une présentation de la configuration et de l’utilisation de [!DNL Report Builder], consultez [Présentation de Report Builder](/help/report-builder/rb-overview.md).
